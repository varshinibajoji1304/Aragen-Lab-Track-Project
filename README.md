## 📌 What is React?

**React** is a JavaScript library used to build **user interfaces** (UI).

### Why React is popular:
- Component-based (reusable UI parts)
- Fast rendering using Virtual DOM
- Easy state management
- Used by companies like Google, Meta, Netflix, etc.

---

## 📌 What is Vite?

**Vite** is a modern build tool that makes frontend development **very fast**.

### Why Vite is used:
- Instant development server start
- Super-fast Hot Module Replacement (HMR)
- Optimized production build
- Very simple configuration

React + Vite = **Speed + Simplicity**
